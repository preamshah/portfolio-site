# Pream Shah — Personal Portfolio

A modern and responsive personal portfolio website designed to showcase my skills, projects, professional experience, and web development background.

## About the Project

This portfolio website represents my work as a Web Developer and Computer Engineer. It provides visitors with information about my technical skills, completed projects, experience, social profiles, and ways to contact me.

## Features

* Modern responsive portfolio design
* Home and introduction section
* About Me section
* Technical skills showcase
* Projects and experience statistics
* Online Store integration
* Downloadable CV
* Contact section
* Social media integration
* Typing text animation
* Scroll reveal animations
* Responsive navigation menu
* Mobile-friendly layout

Clone the repository:

```bash

```

Open the project directory:

```bash
cd YOUR-REPOSITORY
```

Then open `index.html` in your browser.

You can also use the **Live Server** extension in Visual Studio Code for local development.
